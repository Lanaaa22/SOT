# SOT do ConectaFapes

> Este repositório é a Source of Truth (SOT) para organização, arquitetura e planejamento do Sistema ConectaFapes.

## Estrutura do Repositório
```
sua-pasta/
├── SOT/
│   ├── docs/
│   │   ├── assets
│   │   │   ├── fapesLogo.svg
│   │   └── extra.css
│   ├── utils/
│   └── index.md
├─ mkdocs.yml
├── README.md
```

## Como Executar

### Pré Requisitos

* `Python`
* `MkDocs`
  
```bash
# Clone este repositório
git clone https://github.com/Lanaaa22/SOT.git

# Acesse a pasta do projeto
cd seu-repositorio

# Execute a aplicação
mkdocs serve
```

* URL Local:  http://127.0.0.1:8000/
